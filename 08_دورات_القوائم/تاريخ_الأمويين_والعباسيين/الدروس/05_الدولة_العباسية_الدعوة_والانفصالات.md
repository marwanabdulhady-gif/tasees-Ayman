# الدرس ٥ — الدولة العباسية: الدعوة والانفصالات

> **الحالة:** ✅ معتمد — مسودة من المحاضرة الخامسة.

## سؤال الدرس

كيف قامت الدولة العباسية، وما أنواع الحركات والدول التي نشأت داخلها وخارجها؟

## نواتج التعلم

- يصنف الحركات الداخلية: خوارج، أمويون، علويون، باطنية، عجمية/شعوبية.
- يميز بين «الدول المنفصلة» و«الحركات الداخلية».
- يفهم ظاهرة تعدد الخلافات (عباسي + فاطمي + أموي أندلسي + «مايكرو»).

## خريطة المحاضرة

### ١. الحركات الداخلية (00:09–02:16)

5 أنواع:

| النوع | الوصف | أمثلة |
|---|---|---|
| **خوارج** | حركات خارجة متعددة | متعددة جدًا |
| **موالية لأمويين** | تريد إعادة الحكم الأموي | |
| **علويون** | أبناء علي ضد العباسيين | |
| **باطنية** | دعوات دينية جديدة | تكثر في العجم والمهمشين |
| **شعوبية/فارسية** | إحياء عقائد قديمة مع الإسلام | |

بعضها «خطير جدًا»: حركة قعدت ٢٠ سنة، خليفه يجي وراء خليفه يرسل جيوش وما عارفين يقضوا عليها.

### ٢. الدول المنفصلة (01:13–03:20)

آلية الانفصال: الخليفة يبعث واليًا → الوالي يبني جيشًا → يتحول لدولة:

| الدولة | المؤسس | المنطقة |
|---|---|---|
| **الطاهرية** | محمد بن الطاهر | خراسان/ما وراء النهر |
| **الصفارية** | ابن الصفار | |
| **الطولونية** | أحمد بن طولون | مصر |
| **الإخشيدية** | | مصر |
| **الأغالبة** | | شمال أفريقيا |
| **الحمدانية** | | |

### ٣. تعدد الخلافات (03:20–05:30)

| الخلافة | المركز | المذهب |
|---|---|---|
| **عباسي** | بغداد | سنة |
| **فاطمي** | شمال أفريقيا ثم مصر | شيعة إسماعيلية |
| **أموي أندلسي** | الأندلس | سنة |
| **«مايكرو خلافة»** | مناطق صغيرة | متنوعة |

«فاطمي» كانت الأقوى: مسّيطره على الشمال الأفريقي كله لغاية مصر وبتحاول تخش الشام.

### ٤. فكرة الخلافة نفسها (05:30–...)

كل واحد بيقول: أنا مش أقل منهم. — التحول من خلافة واحدة إلى تعدد:
- الأموي في الأندلس أول ما انفصل: كان «أمير الأندلس» (ليس خليفة).
- لما ضعفت العباسية → جاء فاطمي → قال الأموي: **أنا كمان خليفة.**
- ثم كل واحد على حته صغيرة نادى بنفسه خليفة.
