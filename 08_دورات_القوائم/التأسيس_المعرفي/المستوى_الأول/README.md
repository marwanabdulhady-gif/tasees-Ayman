# دورة «التأسيس المعرفي — المستوى الأول»

**الحالة:** ٨ دروس معتمدة من المالك بقالب المشروع + ٨٠ شاشة تفاعلية مولّدة منها · خريطة معتمدة من المالك ·
**المتحدث:** منسوب في أسماء الملفات إلى م. أيمن عبد الرحيم؛ المتحدث لم يتحقق
