## قاعدة البناء

- مصدر ترتيب المحاضرات ورقم الحلقة والرابط هو رأس ملف التفريغ (`الحلقة`، `الرابط`)، لا ترتيب اسم الملف ولا جدول README وحده. توجد جداول README لا تطابق بعض العناوين/الملفات؛ تُصحّح عند المراجعة ولا تُستعمل لتخمين المحتوى.
- كل تصميم كورس يضع **خريطة أولية** من الملفات الموجودة. لا تُكتب دعوى أو هدف تعلم عن محاضرة قبل مراجعة نصها الكامل، ولا تُنسب عبارة للمتحدث إلا مع طابع زمني.
- مسودات الدروس تعليمية داخلية، لا تفريغ بديل ولا نصيحة تخصصية. يظل اعتماد المالك مطلوبًا قبل النشر.
- في السيرة والصحابة والفتن تحفظ حرمة الأشخاص وتُنسب الروايات إلى مصادرها. في علم النفس لا تشخيص ولا إرشاد علاجي.

## ترتيب البناء المقترح

1. تدقيق سجل المصدر وترتيب الحلقات في القوائم الأربع التي لا تملك خريطة كورس بعد.
2. بناء الدرس الأول لكل كورس من النص الكامل، مع رابط الحلقة والطوابع والمهمة التعليمية.
3. اعتماد القالب بعد مراجعة المالك، ثم استكمال الدروس تباعًا.
4. تنظيم قائمة «إعادة تأسيس» كمسارات موضوعية؛ التحقق من ملاءمة كل تسجيل وترتيبها قبل تسميتها كورسًا متسلسلًا.
