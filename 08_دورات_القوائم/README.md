# دورات القوائم — تحويل قوائم التشغيل إلى دروس

مجلد فرعي مستقل داخل مشروع «تأسيس»: يأخذ تفريغات قوائم تشغيل أيمن عبد الرحيم ويحوّلها إلى دروس
مكتوبة بأسلوبه، بأدوات فحص تمنع الانحراف عن النص الأصلي.

| المجلد/الملف | الوظيفة |
|---|---|
| `00_دليل_الأسلوب.md` | قواعد الأسلوب المقيسة من متنه (١٣ ملفًا · ٦٠٬٩٩٨ كلمة) |
| `01_سجل_الحلقات/` | سجل مُولَّد لكل الحلقات: `episodes.json` · `فهرس_الحلقات.md` · `تحذيرات.md` |
| `02_دورة_علم_النفس/` | أول دورة: ١٠ محاضرات ← ١٠ دروس **مكتوبة كلها (مسودات)** · ≈١٦٬٧٢٩ كلمة · ٣٥٢ إحالة |
| `tools/build_playlist_registry.py` | يبني السجل من ملفات الحلقات (لا يقرأ `README.md`) — و`--check` يكشف التقادم |
| `tools/check_lesson.py` | يفحص الدرس: الإحالات · الاقتباسات · البنية · الأرقام |

## التشغيل

```bash
python3 08_دورات_القوائم/tools/build_playlist_registry.py           # بناء السجل
python3 08_دورات_القوائم/tools/build_playlist_registry.py --check   # هل السجل قديم؟ (exit 1 = نعم)
python3 08_دورات_القوائم/tools/check_lesson.py 08_دورات_القوائم/02_دورة_علم_النفس
```

## مبدأ الحكم

- **النص الأصلي هو الحَكَم**: التفريغ في `transcripts/` لا يُعاد كتابته، ولا تُضاف إليه معلومة.
- **الدروس مسودة دائمًا** حتى يقول المالك «خلصت».
- **لا حذف**: أي نسخة جديدة تُوضع بجانب القديمة.
