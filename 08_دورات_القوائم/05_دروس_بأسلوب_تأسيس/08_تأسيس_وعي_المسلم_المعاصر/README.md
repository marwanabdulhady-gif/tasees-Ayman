# تأسيس وعي المسلم المعاصر — دروس بأسلوب التأسيس

> **الدورة:** م. أيمن عبد الرحيم — مدرسة شيخ العمود، صيف ٢٠١٧ (الجمعة ١٨ أغسطس ٢٠١٧ وما بعدها).
> **المصدر:** `transcripts/06-tasees-muslim-awareness/` — ١٧ محاضرة (المستوى الأول ٩ + المستوى الثاني ٨) + ملف قراءة.
> **النوع:** دروس بأسلوب «تأسيس» مبنية على **تفريغ المحاضرات**، لا على نصوص الأسابيع في `02_الوحدات_التعليمية/` (تلك مشروع v0.4 المستقل).
> **الإحالة:** `〔حN MM:SS〕` حيث N = رقم الملف بالترتيب في المجلد.
> **التقدّم:** ١٦ درسًا من ١٦ متاحة — **اكتملت الدورة نصيًّا** (١٦ محاضرة متاحة). الملف السابع عشر (المحاضرة السابعة للمستوى الثاني) متفريغه ٣٠ كلمة فقط: لا يُبنى عليه درس حتى يُفرَّغ يدويًا.

**الحالة:** مسودات — لا تُعدّ نهائية إلا بقرار المالك.
