## الأوامر

```bash
python3 07_الهوية_البصرية_والتفاعل/tools/build_visual_plan.py            # بعد أي تعديل في visual_plan_data.py
python3 07_الهوية_البصرية_والتفاعل/tools/check_svg.py NEW.svg ORIGINAL.svg
python3 07_الهوية_البصرية_والتفاعل/tools/check_drift.py                  # بعد أي تعديل في نصوص الدورة: ما الذي صار قديمًا؟
python3 07_الهوية_البصرية_والتفاعل/tools/build_atlas_links.py            # بعد أي تعديل في ATLAS أو في بيانات الأطلس
python3 07_الهوية_البصرية_والتفاعل/tools/build_visual_plan.py --relock 3 # بعد مراجعة الأسبوع 3 المعدَّل: اقبل نصه الجديد
```
