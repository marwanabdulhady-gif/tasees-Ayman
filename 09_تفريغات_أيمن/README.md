# 09 — تفريغات أيمن عبد الرحيم

خطة وأدوات لجمع تفريغ **كل** دورة ومحاضرة لـ م. أيمن عبد الرحيم، لا القوائم الخمس وحدها.

| الملف | ما هو |
|---|---|
| [`00_خطة_التفريغ.md`](00_خطة_التفريغ.md) | الخطة الكاملة للوكلاء: القواعد، المهام T0–T6، الأشكال، التقرير |
| [`sources.csv`](sources.csv) | **مولَّد** — كل رابط يوتيوب/ساوندكلاود/أرشيف وُجد في تليجرام والوثائق، ومن فُرّغ منه |
| [`00_حالة_المصادر.md`](00_حالة_المصادر.md) | **مولَّد** — العدّ حسب النوع |
| `registry.json` | **يدوي** (مخرج المهمة T1) — المصادر المحققة: المتحدث، الطبعة، الخطة |
| `tools/build_source_catalog.py` | يولّد الملفين أعلاه |

التفريغات نفسها تُكتب في [`../transcripts/`](../transcripts/) كما هي الآن، ومنها تُبنى «دورات القوائم» في [`../08_دورات_القوائم/`](../08_دورات_القوائم/).
