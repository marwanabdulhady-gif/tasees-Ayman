# منصة الأطالس التاريخية والجغرافية التفاعلية
### خرائط التاريخ الإسلامي · الأطلس التاريخي لسيرة الرسول ﷺ · أطلس الخليفة أبي بكر الصديق رضي الله عنه

منصة علمية وتعليمية تفاعلية باللغة العربية (`RTL`)، تعمل **بالكامل دون اتصال بالإنترنت (100% Offline-First)**، تحوّل ثلاثة أطالس تاريخية وجغرافية عربية أصيلة بإجمالي **393 صفحة** و**147 خريطة موثّقة** إلى تجربة استكشاف كارتوغرافي، وبحث موسوعي ذكي، ومقارنة جغرافية، وتعلّم تفاعلي موثّق بالمصادر، مع الحفاظ التام على أمانة المادة الأصلية وإتاحة التحقق البصري المباشر من كل صفحة.

## ١. الأطالس الثلاثة المضمّنة في المنصة

| المجلد | العمل الأصلي | الصفحات | الطبيعة التقنية في المنصة |
|---|---|---:|---|
| **الأول (`maps8`)** | **خرائط التاريخ الإسلامي مجمع** | **8 صفحات** (4 خرائط مزدوجة) | خرائط متجهية مزدوجة مدمجة (`Joined SVG Spreads`) بـ **6 طبقات متجهية حقيقية قابلة للفصل** و**357 معلمًا تفاعليًا** |

## ٢. التشغيل الفوري (دون إنترنت ودون خادم)

### أ. تشغيل الحزمة الكاملة (جميع الـ 393 صفحة بدقتها الكاملة — مستحسن)
1. افتح الملف **`index.html`** مباشرة في أي متصفح حديث (Chrome، Edge، Firefox، Safari) بالنقر المزدوج (`file://`) — **لا يتطلب اتصالًا بالإنترنت ولا خادمًا محليًا ولا أي مفتاح API**.
2. أو شغّل خادمًا محليًا اختياريًا إن رغبت بمشاركته عبر الشبكة المحلية:
   ```bash
   python3 -m http.server 8080 --bind 0.0.0.0
   ```
   ثم افتح `http://localhost:8080`.

### ب. تشغيل النسخة المحمولة وحيدة الملف (Single-File Portable Edition)
- افتح الملف **`release/portable-atlas.html`** (`9.4 MB`): ملف واحد مستقل تمامًا يضم الخطوط العربية (`IBM Plex Sans Arabic`)، والفهرس والبحث والموسوعة والاختبارات لجميع الـ `393` صفحة، مع تضمين الدقة الكاملة لخرائط المجلد الأول المتجهية وأهم الخرائط المحورية والمقارنات من المجلدين الثاني والثالث لسهولة الإرسال عبر البريد أو وحدات التخزين.

## ٣. الوحدات الوظيفية الثماني (Modules A – H)

1. **المستكشف التفاعلي للأطلس (Module A):** تكبير وتصغير سلس حول مؤشر الفأرة أو اللمس، سحب، ملاءمة للشاشة، إعادة ضبط، **تدوير `90°`** للخرائط المطبوعة بالوضع الأفقي (مثل خريطة غزوة أحد ص `165` وخريطة حروب الردة ص `43`)، شريط مصغرات سفلي، ووضع ملء الشاشة.
2. **المعالم الجغرافية التفاعلية والتتبع المصدري (Module B):** `418` معلمًا محققًا بصريًا؛ النقر على أي معلم يعرض بطاقته الموثّقة مع **مقتطف بصري حيّ من الصفحة الأصلية (`Live Source Crop`)** وزر انتقال فوري لمطابقة الأصل.
3. **البحث العربي الذكي والموسوعة الجغرافية (Module C):** يدعم تطبيع الهمزات (`أ / إ / آ / ا`)، والألف المقصورة والياء (`ى / ي`)، والتاء المربوطة والهاء (`ة / ه`)، وحذف التشكيل والتطويل، وتحويل الأرقام العربية والغربية (`ص ١٦٥` أو `ص 165`)، مع إبراز النتائج والتمييز الواضح بين المعالم المحققة ونصوص OCR.
4. **الفهرس الديناميكي الشامل (Module D):** استعراض شبكي أو قائمي لجميع الصفحات الـ `393` مبوبًا وفق الأبواب والفصول الحقيقية للكتب، مع تصفية حسب النوع (خرائط، جداول، صور، نصوص)، والصفحات المحفوظة (`Bookmarks`)، وآخر الصفحات المتصفحة.
5. **عارض الصفحات الأصلية والمطابقة جنبًا إلى جنب (Module E):** فحص عالي الدقة لأي صفحة من الصفحات الـ `393` كما وردت في المصدر تمامًا، مع وضع **المطابقة البصرية المزدوجة** (العرض التفاعلي بجانب الصورة الأصلية الخام) وبصمة `SHA-256`.
6. **مفاتيح الخرائط والطبقات التفاعلية الصادقة (Module F):** تحكم مستقل بالطبقات المتجهية الست في المجلد الأول، وإظهار/إخفاء طبقة المعالم المحققة وطبقة كلمات OCR في المجلدين الممسوحين، مع حفظ مفاتيح الألوان ومقاييس الرسم الأصلية.
7. **المقارنة الجغرافية والتاريخية (Module G):** مقارنة لوحتين جنبًا إلى جنب بتكبير متزامن، أو عبر **شريط السحب المتطابق (`Swipe Curtain`)** للخرائط المتطابقة هندسيًا (`شكل ١-١` مقابل `شكل ١-٤`)، إضافة إلى مقارنات عابرة للمجلدات (الهجرة النبوية، حروب الردة، طلائع الفتوحات).
8. **التعلّم والاكتشاف المعرفي (Module H):** بطاقات استذكار (`Flashcards`)، واختبارات اختيار من متعدد موثّقة بالمصدر، وتحدي **«أين يقع هذا المعلم على الخريطة؟»**، مع إمكانية تفعيل **«وضع المرجع العلمي فقط»** لإخفاء جميع عناصر التعلّم بنقرة واحدة.

## ٤. اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `/` | التركيز الفوري في شريط البحث الشامل |
| `+` / `-` | تكبير / تصغير الخريطة النشطة |
| `0` | ملاءمة الخريطة للشاشة |
| `r` | تدوير الخريطة `90°` |
| `←` / `→` | الانتقال إلى الصفحة التالية / السابقة (مراعٍ لاتجاه العربية RTL) |
| `Escape` | إغلاق قائمة البحث أو إلغاء تحديد المعلم النشط |

```text
├── index.html                  # الواجهة الرئيسية المستقلة (تعمل عبر file:// و http://)
├── release/
│   └── portable-atlas.html     # النسخة المحمولة وحيدة الملف (9.4 MB)
├── assets/
│   ├── fonts/                  # خطوط IBM Plex Sans Arabic المضمّنة محليًا (woff2 + OFL)
│   ├── pages/{maps8,seerah,abubakr}/   # جميع الصفحات الـ 393 بصيغة WebP عالية الدقة
│   ├── thumbs/{maps8,seerah,abubakr}/  # مصغرات سريعة لجميع الصفحات الـ 393
│   └── svg/maps8/              # الخرائط المتجهية المفصولة إلى طبقات للمجلد الأول
├── data/
│   ├── manifest.json           # السجل المصدري الموحّد (393 صفحة، 608 معالم، الإحصاءات)
│   ├── verified_indexes.json   # النسخ المحقق بصريًا لفهارس المجلدين الثاني والثالث
│   ├── verified_curated_maps.json # المعالم والمفاتيح المحققة بصريًا على الخرائط المحورية
│   ├── ocr/{seerah,abubakr}.json  # مخرجات الاستخراج الضوئي الكامل مع الإحداثيات والثقة
│   ├── atlas-bundle.js         # حزمة البيانات للعمل دون خادم عبر file://
│   ├── ocr-words-bundle.js     # حزمة إحداثيات كلمات OCR
│   └── maps8-vectors.js        # حزمة الخرائط المتجهية المضغوطة
├── src/
│   ├── styles.css              # نظام التصميم الكارتوغرافي العربي (RTL + وضع نهاري/ليلي)
│   └── js/                     # الوحدات البرمجية (utils, panzoom, viewer, search, compare, learn, app)
├── docs/
│   ├── CONTENT-AUDIT.md        # تقرير التدقيق العلمي والمحتوى (Deliverable C)
│   ├── PAGE-INVENTORY.md       # الجرد التفصيلي لجميع الصفحات الـ 393
│   └── KNOWN-LIMITATIONS.md    # وثيقة القيود التقنية والعلمية (Deliverable E)
└── tools/                      # سكربتات الاستخراج وبناء البيانات والنسخة المحمولة واختبارات QA
```

### إعادة توليد البيانات والنسخة المحمولة وتشغيل اختبارات الجودة (QA)
```bash
# ١. إعادة بناء السجل المصدري الموحّد وحزم file://
.venv/bin/python tools/build_unified_manifest.py

# ٢. إعادة بناء النسخة المحمولة وحيدة الملف وملف الجرد الكامل
.venv/bin/python tools/build_portable_html.py
.venv/bin/python tools/generate_docs.py

# ٣. تشغيل حزمة اختبارات المتصفح الآلية دون إنترنت (27 فحصًا عبر file://)
node tools/qa/run_qa.cjs
```
