## منصة الأطالس التاريخية والجغرافية التفاعلية (مدموجة من `main` — PR #3)

يضم جذر المستودع أيضًا منصة عربية تفاعلية تعمل بالكامل دون اتصال (`Offline-First`)، تحوّل سبعة أطالس تاريخية وجغرافية — «خرائط التاريخ الإسلامي»، والأطلس التاريخي للسيرة النبوية، وأطالس الخلفاء الراشدين الأربعة (أبو بكر وعمر وعثمان وعلي) لسامي بن عبد الله المغلوث، و«أطلس دول العالم الإسلامي» لد. شوقي أبو خليل — بإجمالي **1,597 صفحة** و**603 خريطة مفهرسة** إلى تجربة استكشاف وبحث ومقارنة.

وتضمّ المنصة الآن **مجموعة الأطالس الإضافية** ([`atlas-modules/`](atlas-modules/index.html)): أطلس السلالات الإسلامية (186 سلالة، 13,940 ترجمة — أوفلاين، عربي/RTL)، وأطلس القرآن (نسخة عربية)، مع توثيق مصادر uMap والموقع التجاري المرجعي.

| المدخل | الوصف |
|---|---|
| `index.html` | الحزمة الكاملة — كل الصفحات الـ 1,597 بدقتها الأصلية + مسار دورة «تأسيس» والمحاضرات (`#tab=courses`) والروابط العميقة (`#page=...&hs=...`) |
| `release/portable-atlas.html` | النسخة المحمولة وحيدة الملف (تضم المحرك الكامل ومسار دورة «تأسيس» و122 صفحة خريطة وغلافًا مدمجة بصريًا) |
| `atlas-modules/index.html` | بوابة الأطالس الإضافية: أطلس السلالات الإسلامية (`islamic-dynasties/public/index.html`) وأطلس القرآن الكريم (`atlas-of-quran/index.html`) |
| `data/` و`assets/` | بيانات المنصة وأصولها (770 معلمًا محققًا عبر 173 خريطة تفاعلية، SVG للخرائط المتجهية، حزم OCR، البيان الفهرسي) |

المنصة مضافة كما هي من فرعها الأصلي — لا تتداخل مع مجلدات مشروع تأسيس (00–99) أعلاه، وتفاصيلها الكاملة في تاريخ `main` (README الأصلي للمنصة محفوظ في سجل الدمج).

## منصة الأطالس: تدقيق ونسخ ضوئي لثلاثة ملفات PDF (PR #2)

القسم التالي من عمل فرع `arena/24dfd4be-tasees-ayman` (PR #2)، وهو **مكمّل** لمنصة الأطالس أعلاه ولا يحل محلها.

إضافةً إلى أطلس الخرائط الثماني المكتمل أعلاه، جرى تدقيق ثلاثة ملفات PDF
قدّمها المستخدم، مجموع صفحاتها **٣٩٣ صفحة**:

| المعرّف | الملف | الصفحات | طبقة نصية | خطوط مضمّنة |
|---|---|---:|---:|---:|
| `sira` | الأطلس التاريخي لسيرة الرسول.pdf | 264 | 0 | 0 |
| `abubakr` | أطلس الخليفة أبي بكر الصديق.pdf | 121 | 0 | 0 |
| `islamic-maps` | خرائط التاريخ الإسلامي مجمع.pdf | 8 | 0 | 0 |

الملفات الثلاثة **ممسوحة ضوئيًا بالكامل**: لا توجد طبقة نصية ولا خطوط مضمّنة،
لذا فإن النسخ الضوئي العربي إلزامي لكل صفحة. نتائج التدقيق مُقاسة فعليًا في
[`docs/CORPUS-AUDIT.md`](docs/CORPUS-AUDIT.md)، وجرد الصفحات الآلي في
`data/page_inventory.json`، وبيانات المصادر (بما فيها بصمات SHA-256 ومعرّفات
Drive) في `data/source_documents.json`.

### ما أُنجز في هذا الفرع

- `tools/audit_pdf.py` — جرد صفحة بصفحة لكل الملفات + تقرير تدقيق.
- `tools/extract_assets.py` — صور صفحات بأمانة المصدر (WebP) ومصغّرات.
- `tools/prepare_ocr_images.py` — صور مُحسّنة للنسخ الضوئي.
- `tools/ocr/` — محرك Tesseract.js LSTM عربي **محلي بالكامل** (نواة WASM
  ونماذج `tessdata_fast` محمّلة من GitHub API وقت البناء فقط)، مع إحداثيات
  الكلمات ودرجات الثقة، وقابلية الاستئناف. **اكتمل النسخ الضوئي للصفحات الـ393**
  (117٬732 كلمة بمتوسط ثقة 55.4 — كلها موسومة `ocr-unverified`).
- `tools/build_corpus_index.py` → `data/corpus_index.json`: فهرس مضغوط لكل صفحة
  (القسم من الإشارات المرجعية، الأصول، النص المنسوخ، ونص بحث مُطبَّع).
- [`docs/PIPELINE.md`](docs/PIPELINE.md) — خطوات إعادة البناء،
  و [`docs/KNOWN_LIMITATIONS.md`](docs/KNOWN_LIMITATIONS.md) — حدود صريحة.

### سياسة الدقة (تسري على كل المراحل)

- ملفات PDF هي المرجع الوحيد؛ لا أسماء أماكن ولا إحداثيات ولا حدود مُخترعة.
- نص النسخ الضوئي يُخزَّن كما هو مع علامات ثقة؛ تطبيع البحث يغيّر **الفهرس فقط**
  ولا يغيّر النص المعروض.
- كل حقيقة مستخرجة تحتفظ بـ `documentId` و `sourcePage` للتحقق في عارض الصفحة الأصلية.
- لا يوصف أي رسم بأنه «تفاعلي بالكامل» إذا كان يدعم التكبير والتحريك فقط،
  ولا تُرسم حدود جغرافية تفاعلية مزيّفة.

> **تنبيه للمراجع:** الصور المولّدة (`assets/pages/<docId>/`) وبيانات النسخ
> الضوئي (`assets/ocr/`) وملفات PDF الكبيرة غير مُدرجة في git (انظر `.gitignore`)؛
> تُعاد توليدها بالأوامر في `docs/PIPELINE.md`. المخرج الجاهز الوحيد المُدرج
> حاليًا هو `release/islamic-history-atlas.html`.
