## الحكم السحابي الموثق (تاريخي)

٦ تشغيلات GitHub Actions أثبتت: يوتيوب يرد «Sign in to confirm you're not a bot» على كل عناوين مراكز البيانات عبر كل المكتبات (youtube-transcript-api/ytfetcher، yt-dlp بكل player clients، pytubefix بكل عملائه الستة) وكل الواجهات العامة (Invidious — بما فيها inv.nadeko.net التي تُرجع جسمًا فارغًا — وPiped). الحل العملي: Supadata API بمفتاح، أو تشغيل محلي على إنترنت سكني (`get_transcripts_windows.bat` / `get_transcripts_mac_linux.sh` — ما زالا صالحين للاستئناف مستقبلًا).

## طبقة الأتمتة (باقية للمستقبل)

- **Workflow:** `.github/workflows/fetch-transcripts.yml` — push على المسارات المحددة أو يدوي عبر Actions (مدخلات: `only`, `limit`)؛ يلتزم النتائج تلقائيًا ويستأنف.
- **السكريبت:** `scripts/fetch_transcripts.py` — الترتيب: ytfetcher ← yt-dlp ← pytubefix ← Invidious ← Piped (وتدعم الكوكيز عبر سرّ `YT_COOKIES` لـyt-dlp وpytubefix).
- **الإضافة الجديدة:** أي قائمة/حلقة مستقبلية تُضاف إلى `transcripts/playlists.json` ويُعاد التشغيل.
