# الوحدة 3 — السلطة والخلاف والانتماء في التاريخ المبكر

**الدورة:** من اليقين إلى الوعي والعمل  
**الأسابيع:** 9–12 من البرنامج ذي 24 أسبوعاً  
**النمط:** تحضير ذاتي موجّه + لقاء مباشر (120 دقيقة) + مجموعة تعلم + تطبيق قصير  
**الحالة:** مسودة إنتاجية `v0.1` — مشروطة ببوابة مراجعة الوحدة 2 وبـPilot آمن قبل الاعتماد.

## السؤال الجامع

> كيف نقرأ السلطة والخلاف والانتماء في التاريخ الإسلامي المبكر من غير تقديس التاريخ أو ازدرائه، ومن غير تحويل رواية تاريخية إلى حكم فوري على جماعة حاضرة؟

## نواتج الوحدة

بنهاية الوحدة يستطيع المتعلم أن:

1. يبني خطاً زمنياً متعدد الطبقات: حدث، فاعلون، مصدر، قراءة لاحقة، وموضع عدم يقين.
2. يفرّق بين التوصيف التاريخي، والحكم الأخلاقي، والحكم العقدي/الفقهي، والاستعمال السياسي المعاصر.
3. يحلل ادعاءً عن سلطة أو خلاف أو دولة عبر المصدر والنطاق والقراءة البديلة وحدود الاستنتاج.
4. يرسم خريطة نظم تربط الحاكم والنخب والجيش والعلماء والاقتصاد والعامة، بلا اختزال لشخص واحد أو «سبب واحد».
5. يقدم معرضاً صغيراً عن تعدد المراكز وتبادل المعرفة، مع تسمية ما توثقه المصادر وما يبقى تفسيراً.

## حدود تربوية غير قابلة للتفاوض

- لا تُحوَّل الجلسات إلى محكمة عقائدية أو جدل طائفي أو تصنيف معاصرين.
- لا تكرر أوصافاً مهينة لشخصيات أو جماعات؛ حلل الدعوى والدليل والسياق.
- لا يستعمل التاريخ لتبرير عنف أو إقصاء أو مشروع سياسي حالي.
- لا يقدم عرض حلقات المصدر بوصفه حكماً نهائياً، ولا يساوي بين كل الروايات أو المناهج.
- تفريغات YouTube الآلية دلائل موضعية فقط؛ يراجع الميسر الفيديو الأصلي قبل الاقتباس أو العرض.

## معيار المصدر

سجل الموارد لا يمنح المورد صفة «موصى به» لمجرد وروده في حلقة. كل مورد يحمل دوراً وحالة تحقق وملاحظة حقوق ومخاطرة ادعاء. الموارد شديدة الحساسية تُستعمل كأمثلة لتحليل الاستدلال فقط، أو تبقى محجوزة إلى مراجعة مختص.
