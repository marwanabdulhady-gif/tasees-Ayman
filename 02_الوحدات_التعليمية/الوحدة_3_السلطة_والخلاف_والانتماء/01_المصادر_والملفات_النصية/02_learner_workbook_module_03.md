| المركز الأول والمركز الثاني | |
| الوسيط أو الطريق | |

| ماذا يثبت المصدر مباشرة؟ | |

## مذكرة تحليل الحالة (صفحتان كحد أقصى)

1. سؤال محدد.  
2. خط زمني قصير.  
3. مصدر واحد على الأقل، وموضعه.  
4. دعوى محدودة وقراءة بديلة.  
5. ما الذي لا أحسمه؟  
6. درس تربوي/حياتي لا يتحول إلى وصفة سياسية.
