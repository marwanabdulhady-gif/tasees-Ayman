# الوحدة 4 — أنماط القوة والضعف والتحول

**الدورة:** من اليقين إلى الوعي والعمل  
**الأسابيع:** 13–16 من البرنامج ذي 24 أسبوعاً  
**النمط:** تحضير ذاتي موجّه + لقاء مباشر (120 دقيقة) + مجموعة تعلم + تطبيق قصير  
**الحالة:** مسودة إنتاجية `v0.1` — مشروطة ببوابة مراجعة الوحدة 3 وPilot آمن قبل الاعتماد.

## السؤال الجامع

> كيف نفسر القوة والضعف والتحول التاريخي من غير عبادة البطل، أو لوم الضحية، أو اختزال السقوط في سبب واحد، أو تحويل التاريخ إلى وصفة سياسية للحاضر؟

## نواتج الوحدة

بنهاية الوحدة يستطيع المتعلم أن:

1. يفرّق بين دور الشخص، وشروط المؤسسة، والسياق الأوسع في تفسير نجاح أو إخفاق تاريخي.
2. يبني تفسيراً متعدد الأسباب يميّز بين العامل القريب، والعامل البنيوي، والصدفة/الطارئ، والدليل اللازم لكل منها.
3. يحلل سرداً عن الفقد أو السقوط دون لوم جماعي أو حتمية تاريخية أو «خيانة واحدة» تفسر كل شيء.
4. يقرأ التاريخ العثماني خارج الثنائية الساذجة «مجد كامل/احتلال كامل»، مع تعريف المصطلحات قبل إصدار الأحكام.
5. يرسم نموذجاً سببياً قابلاً للنقد يربط الضغط الخارجي والقابلية الداخلية والوسائط الناقلة وشبكات العلاقات بالتحول الطويل.

## حدود تربوية غير قابلة للتفاوض

- لا تُحوَّل القوة العسكرية أو العنف إلى بطولة أو نموذج سلوك؛ يدرس القرار والمؤسسة والسياق والنتائج الإنسانية.
- لا يفسر الفقد أو السقوط بعيب ثابت في شعب/دين/عرق أو بلوم جماعي أو بنظرية مؤامرة شاملة.
- لا تُستخدم «الخيانة» أو «الاحتلال» أو «التحرر» كألفاظ حاسمة قبل تحديد الفاعل والزمن والمعيار والمصدر.
- لا يستعمل التاريخ لتبرير عنف، أو للتحريض على خصومة، أو لاستخراج مشروع سياسي حاضر.
- حلقات المصدر وتفريغات YouTube الآلية دلائل موضعية فقط؛ يراجع الميسر الفيديو الأصلي قبل الاقتباس أو العرض.
- مواد دورة أيمن تعرض إطار صاحبها عن الأفكار والشبكات والمؤسسات؛ تُحلل بوصفها دعوى/عدسة، لا نظرية حاسمة أو تفسيراً وحيداً.
