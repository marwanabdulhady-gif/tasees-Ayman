# بروتوكول Pilot — الوحدة 4

## العينة والأمان

10–20 بالغاً عبر المسارات الثلاثة. الموافقة واضحة: لا يقيس Pilot الهوية أو الولاء أو الموقف السياسي. يحق للمتعلم المرور أو طلب حالة عامة. لا تسجيل صوت/فيديو، ولا اقتباس شخصي بلا موافقة منفصلة.

## القياس

| الوقت | الأداة | ماذا تقيس؟ |
|---|---|---|
| قبل الأسبوع 13 | مهمة 0–8 | فصل الشخص/المؤسسة/السياق؛ عامل/آلية/حد. |
| كل أسبوع | 4 بنود 1–5 + سؤال مفتوح | وضوح، أمان، عبء، مقاومة الاختزال. |
| أثناء الحوار | ملاحظة مجهلة | تعريف مصطلح، سؤال مصدر، عامل غائب، حد، لوم جماعي/تمجيد. |
| بعد الأسبوع 16 | مهمة 0–8 + مذكرة مصغرة | نموذج متعدد العوامل، قراءة بديلة، وحد. |
| بعد 7–10 أيام | تحقق اختياري | هل صحح المتعلم تفسير «سبب واحد» في محتوى يقرأه/يشاركه؟ |

## مهمة قبل/بعد (0–8)

**A، أربع نقاط:** «نجحت دولة لأن قائدها عبقري، ثم سقطت لأن شعبها خانها». يفصل المتعلم الفرد/المؤسسة/السياق، ويحدد لفظين يحتاجان دليلاً أو تعريفاً.  
**B، أربع نقاط:** أمامه وصف قصير لتحول تاريخي؛ يكتب عاملين وآليتين، قراءة بديلة، وحداً لا يجوز تجاوزه.

## بنود الأسبوع (1–5)

1. استطعت أن أفرق بين عامل وآلية وبين تفسير وحكم.
2. تمكنت من السؤال أو المرور بلا ضغط أو سخرية أو طلب هوية.
3. كان التحضير مناسباً للوقت المعلن.
4. ساعدني النشاط على مقاومة السبب الواحد أو اللوم الجماعي.

## عتبات القرار

- **أخضر:** 70%+ يسمون عاملاً وآلية وحداً، و80%+ يقيّمون الأمان 4–5.
- **أصفر:** 50–69% أو خلط متكرر؛ صغّر الحالة وزد الكتابة الصامتة وتعريف المصطلحات.
- **أحمر:** أي بلاغ استهداف/تمجيد عنف/لوم جماعي أو أقل من 60% أمان؛ أوقف الحالة وراجع التصميم.

لا يستخدم أي رقم لترتيب المشاركين أو تصنيفهم دينياً أو وطنياً أو سياسياً.
