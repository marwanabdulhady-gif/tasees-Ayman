# بروتوكول التشغيل التجريبي — الوحدة 3 v0.4 (أسابيع 9–12)

**المدة:** 4 أسابيع (20–168 يومًا حسب المسار). **المشاركون:** ميسر + 3–8 متعلمين.

## المسارات
| المسار | الجرعة |
|---|---|
| مكثف | 20 يومًا: لقاء 120د ×4 + تحضير يومي |
| عادي | 28 يومًا: لقاء أسبوعي + حلقة + تحضير 35–45د |
| خفيف | 168 يومًا: أسبوع راحة بين اللقاءات |

## جدول الوحدة
| الأسبوع | الحلقة | المهمة البعدية |
|---|---|---|
| 9 | لغتك مش هدومك | خريطة لساني + بطاقة كلمة شحنة |
| 10 | الجذر أداة | بطاقتا جذر + عادة «الوزن زاد إيه» |
| 11 | النحو مش كرابيج | قراءة معلمة + قراءة بصوت قبل الإرسال |
| 12 | اللغة مشروع | ملف و3 بخمس مكونات + مشروع معلن |

## القياس بعد كل لقاء
وضوح/أمان/عبء (1–5) + مهارة واحدة سمّاها متعلم.

## معايير التعديل
- وضوح أو أمان <3 لأسبوعين → تعديل النص/الأزمنة.
- حوار اللغة تحول لخنادق فصحى/عامية → إيقاف النشاط والعودة لاتفاق الحوار.
- عبء >4 → قص المهمة البعدية لمكوّن واحد.
