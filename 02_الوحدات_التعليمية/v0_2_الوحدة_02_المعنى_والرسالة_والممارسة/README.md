# الوحدة 2 v0.2 — الرسالة والقدوة والمعنى والممارسة

**الدورة:** من اليقين إلى الوعي والعمل  
**الأسابيع:** 5–8 من مسار 24 أسبوعاً  
**النمط:** تحضير ذاتي موجّه + لقاء حي 120 دقيقة + تجربة اختيارية منخفضة المخاطر  
**المسارات:** مستكشف 18–30، ممارس عام، وباحث/معلّم متقدم.  
**الحالة:** حزمة إنتاجية مستقلة v0.2؛ تحفظ v0.1 ولا تستبدلها.

## السؤال الجامع

> كيف تتحول الرسالة والقدوة والعبادة والأفق الأخروي إلى معنى وممارسة من غير إكراه أو اختزال أو رقابة أو سلطة روحية؟

## ما الجديد عن v0.1

ينقل الإصدار v0.2 مركز الوحدة من مناظرات السيرة الحساسة إلى: **وظيفة المصدر، القدوة، نوع سؤال المعنى، الممارسة الاختيارية، والتزكية بوصفها رعاية وحدوداً**. تنتقل مواد الفتنة/السلطة والأسئلة التاريخية الحساسة إلى الوحدة 3 وفق المخطط الرئيس؛ تبقى مسجلة في سجل الموارد لاستخدامها المتتبع لاحقاً، لا كتدريس مباشر هنا.

## حواجز لا تفاوض عليها

- لا اختبار اعتقاد أو طلب إفصاح تعبدي أو شخصي.
- لا مراقبة أو قياس أو مقارنة لممارسة دينية أو غيرها.
- لا تقديم للسيرة أو للمصدر المعياري كقالب سياسي أو تنظيمي حاضر.
- لا علاج نفسي أو فتوى فردية أو علاقة سلطة روحية؛ توجد إحالة واضحة عند الحاجة.
- جماعة التعلم مؤقتة ومدنية/تعليمية، والأدوار قابلة للدوران والاعتراض.
