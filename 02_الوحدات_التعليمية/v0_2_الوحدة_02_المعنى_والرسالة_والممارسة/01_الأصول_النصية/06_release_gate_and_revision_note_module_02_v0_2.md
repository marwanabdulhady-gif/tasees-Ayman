# بوابة الإصدار والمراجعة — الوحدة 2 v0.2

## قبل Pilot أو التشغيل
- [ ] راجع الميسر مواضع PDF/الفيديو الأصلية، لا transcript وحده.
- [ ] تحقق أن كل نشاط يحفظ حق المرور والحالة الافتراضية.
- [ ] جهز مسار إحالة محلياً للاستشارة النفسية/الفقهية/الحماية؛ لا يعالج الميسر الحالات.
- [ ] أزل كل سؤال أو جدول يقيس ممارسة أو شعوراً دينياً أو يطلب قصة شخصية.
- [ ] أكد أن المواد المؤجلة للوحدة 3 لا تظهر كمناظرة أو درس مباشر هنا.

## قرار التشغيل
| القرار | الشرط | الإجراء |
|---|---|---|
| ابدأ | 70%+ يميزون المصدر/القيمة/الممارسة؛ 80%+ أمان 4–5؛ لا مؤشر ضغط | شغّل مع سجل أسئلة مجهول وتحسينات صغيرة. |
| ابدأ مخففاً | عبء متوسط أو ارتباك في نوع السؤال | مادة واحدة قصيرة، حالات افتراضية، وممارسة غير شخصية. |
| أوقف وأعد التصميم | ضغط على الإفصاح/الممارسة، ادعاء علاج/سلطة، أو أمان أقل من 60% | أوقف النشاط، راجع اللغة والإحالة وتدريب الميسر. |

## حواجز لا تتجاوز
لا اختبار اعتقاد؛ لا قياس عبادة أو تدين؛ لا وسم جماعي؛ لا سلطة روحية؛ لا تجنيد/ولاء تنظيمي؛ لا نقل للتاريخ إلى برنامج سياسي؛ ولا فعل يتجاوز التعلم المدني الآمن.
