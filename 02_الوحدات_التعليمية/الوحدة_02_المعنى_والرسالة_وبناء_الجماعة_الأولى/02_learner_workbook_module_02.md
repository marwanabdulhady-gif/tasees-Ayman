# الأسبوع 6 | من الدعوى إلى خريطة الدليل

## 1. خريطة دليل

اختر دعوى واحدة مختصرة من مادة الأسبوع، أو استخدم: «هذه الرواية تخبرنا شيئاً مهماً عن فهم جماعة مبكرة للرسالة.» لا تحوّلها إلى حكم أكبر مما تسمح به المادة.

| خانة الخريطة | املأ بدقة |
|---|---|
| الدعوى بعبارة واحدة | |
| هل هي تاريخية، دينية/معيارية، تفسيرية، أم مركبة؟ | |
| المصدر الذي أمامي (النوع، المؤلف/الناقل إن عُرف، الزمن، الغرض) | |
| ما الذي يثبته المصدر مباشرة؟ | |
| ما الذي أضفته أنا كتفسير أو افتراض؟ | |
| مصدر آخر/نوع مصدر آخر أحتاجه | |
| اعتراض منصف محتمل | |
| ردي المؤقت على الاعتراض | |
| درجة الثقة: منخفضة / متوسطة / مرتفعة، ولماذا؟ | |
