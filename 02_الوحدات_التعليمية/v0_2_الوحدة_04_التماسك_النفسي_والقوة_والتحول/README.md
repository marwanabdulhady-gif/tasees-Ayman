# الوحدة 4 v0.2 — التماسك النفسي والقوة والتحول

**الأسابيع:** 13–16 من برنامج 24 أسبوعاً.  
**السؤال الجامع:** كيف نفسر الصمود والفقد والتحول من غير عبادة بطل، أو لوم من يعاني، أو حتمية، أو وصفة سياسية؟  
**الحالة:** بناء مستقل v0.2؛ لا يستبدل الوحدة 4 v0.1.

## دور «أين الطريق؟» المحدود
تدخل AT-08 وAT-00 وAT-04 وAT-09 كمواد أولية متتبعة: لغة وأسئلة وعدسات تربوية تحتاج تحديد وظيفة وحدّاً ودليلاً. لا تصبح AT-08 علاجاً أو مقياساً للصحة النفسية أو الصمود؛ ولا تصبح الروابط نموذج تنظيم أو ولاء؛ ولا يصبح التحليل التاريخي برنامجاً سياسياً للحاضر.

## حواجز ثابتة
لا لوم لمن يعاني؛ لا اختبار مرونة أو صحة نفسية؛ لا تمجيد للعنف؛ لا مؤامرة كلية أو عيب ثابت أو لوم جماعي؛ لا سؤال عن الهوية أو الخبرة الشخصية؛ لا تجنيد أو ولاء أو سلطة؛ ولا تطبيق سياسي/تنظيمي حاضر.
