## بوابة مصغرة قبل كل لقاء
- [ ] اختيار حالة واحدة صغيرة ومراجعة أصلها.

- [ ] لا طلب تجربة شخصية ولا قياس صمود أو حالة نفسية.
- [ ] كل تفسير يحمل مصدراً أو افتراضاً أو حدّاً.
- [ ] لا تطبيق سياسي/تنظيمي أو لغة ولاء أو تعبئة.
