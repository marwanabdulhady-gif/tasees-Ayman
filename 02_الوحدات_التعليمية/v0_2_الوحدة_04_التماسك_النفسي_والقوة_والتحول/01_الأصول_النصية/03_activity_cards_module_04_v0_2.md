# بطاقات النشاط — الوحدة 4 v0.2

استخدم حالة افتراضية أو تاريخية ضيقة بعد مراجعة المصدر. لا تطلب خبرة شخصية ولا تدفع إلى حكم على جماعات أو سياسات حاضرة.

## C1 — بطاقة شخص/مؤسسة/سياق

**التنفيذ:** وزع بطاقات عامل. رتّبها في فرد/مؤسسة/سياق/طارئ. أضف نوع دليل وحداً.
**المخرج:** فرد/مؤسسة/سياق/طارئ/دليل/حد
**الحاجز:** حق المرور؛ حالة افتراضية أو مهنية؛ لا هوية أو إفصاح أو تعبئة.

## C2 — اختبار الرواية البطولية

**التنفيذ:** حوّل «فلان صنع التاريخ» إلى عبارة شروط وآليات، ثم اكتب ما لا تقوله.
**المخرج:** صياغة محدودة بلا تمجيد أو لوم
**الحاجز:** حق المرور؛ حالة افتراضية أو مهنية؛ لا هوية أو إفصاح أو تعبئة.

## C3 — عيادة الأسباب

**التنفيذ:** ضع العامل في أكثر من خانة عند الحاجة: قريب/بنيوي/آلية/مسرع/طارئ.
**المخرج:** تفسير متعدد لا حتمي
**الحاجز:** حق المرور؛ حالة افتراضية أو مهنية؛ لا هوية أو إفصاح أو تعبئة.

## C4 — سلسلة عامل/آلية/أثر

**التنفيذ:** ارسم مساراً ثم ضع نقطة قطع أو شرطاً غائباً وقراءة بديلة.
**المخرج:** سلسلة مع انقطاع وحد
**الحاجز:** حق المرور؛ حالة افتراضية أو مهنية؛ لا هوية أو إفصاح أو تعبئة.

## C5 — مختبر المصطلحات

**التنفيذ:** لكل لفظ: نوعه، فاعله، زمنه، مكانه، معياره، مصدره، وحده.
**المخرج:** بطاقة نطاق لا شعار
**الحاجز:** حق المرور؛ حالة افتراضية أو مهنية؛ لا هوية أو إفصاح أو تعبئة.

## C6 — خريطة نظم قابلة للنقد

**التنفيذ:** ارسم عقداً وأسهمًا. ضع على كل سهم: دليل أو افتراض. أضف صوتاً غائباً.
**المخرج:** خريطة لا تفترض تجانساً أو ولاء
**الحاجز:** حق المرور؛ حالة افتراضية أو مهنية؛ لا هوية أو إفصاح أو تعبئة.

## C7 — خريطة التحول

**التنفيذ:** حدد مورداً ووسيطاً ومؤسسة وقيداً ونقطة قطع.
**المخرج:** نموذج مؤقت قابل للنقد
**الحاجز:** حق المرور؛ حالة افتراضية أو مهنية؛ لا هوية أو إفصاح أو تعبئة.

## C8 — خطة رعاية وتعلّم وفعل صغير

**التنفيذ:** صمّم دعماً اختيارياً وحداً وبديلًا وفعلًا صغيراً ومؤشر مراجعة وإحالة عند الحاجة.
**المخرج:** خطة ليست علاجاً وليست إلزاماً
**الحاجز:** حق المرور؛ حالة افتراضية أو مهنية؛ لا هوية أو إفصاح أو تعبئة.
