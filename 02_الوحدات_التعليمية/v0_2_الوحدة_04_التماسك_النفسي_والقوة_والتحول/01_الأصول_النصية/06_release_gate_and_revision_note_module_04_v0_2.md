# بوابة الإصدار والمراجعة — الوحدة 4 v0.2

## لا تصدر قبل تحقق كل بند
- [ ] الميسر راجع المصدر الأصلي لكل اقتباس/رقم/اتهام تاريخي حساس.
- [ ] لا تستخدم حلقة أو تفريغاً آلياً بوصفه حكماً نهائياً أو مصدراً وحيداً.
- [ ] كل نشاط يحمل حق المرور وحالة افتراضية أو مهنية بديلة.
- [ ] حُذفت لغة قياس الصمود أو الصحة النفسية أو العلاج أو الوعد بالتحول.
- [ ] حُذفت لغة البطولة العسكرية واللوم الجماعي والحتمية والمؤامرة الكلية.
- [ ] لا يخرج أي نشاط بتطبيق سياسي أو تنظيمي أو تعبوي أو لغة ولاء.
- [ ] المسارات الثلاثة متاحة بلا ترتيب لقيمة المتعلمين.
