**ما يمنعه الباني:** أقل من ١٠ أو أكثر من ١٣ شاشة · أول شاشة ليست L1 أو آخر شاشة ليست L7 ·
ثلاث L3 متتالية · نمط خارج خطة الأسبوع أو بترتيب مخالف · نمط بلا `data` · L7 بلا ثلاث سطور/إعادة/مهمة المسارات الثلاثة.
