# الوحدة 5 — الحداثة والاستعمار والهوية

**الدورة:** من اليقين إلى الوعي والعمل  
**الأسابيع:** 17–20 من البرنامج ذي 24 أسبوعاً  
**النمط:** تحضير ذاتي موجّه + لقاء مباشر (120 دقيقة) + مجموعة تعلم + تطبيق قصير  
**الحالة:** مسودة إنتاجية `v0.1` — مشروطة ببوابة مراجعة الوحدة 4 وPilot آمن قبل الاعتماد.

## السؤال الجامع

> كيف ندرس الاستعمار والدولة الحديثة والحدود والهوية بوضوح تاريخي وكرامة إنسانية، من غير اختزال الناس في كتل، أو جعل الماضي تفسيراً وحيداً للحاضر، أو تحويل التعلم إلى استقطاب سياسي؟

## نواتج الوحدة

بنهاية الوحدة يستطيع المتعلم أن:

1. يفرق بين الاحتلال والاستعمار والإمبراطورية والهيمنة، ويحدد متى تكون المصطلحات وصفية أو معيارية أو قانونية.
2. يقارن وثيقتين أو روايتين عن سياق استعماري عبر المنشئ والغرض والجمهور والغياب والنطاق، من غير مساواة زائفة بين القوة والخبرة.
3. يرسم خريطة مؤسسة تبين ما الذي تكافئه المدرسة/الجامعة/العمل/الأسرة وما الذي قد تضعفه، مع فصل الوصف عن التوصية.
4. يبني خطاً زمنياً محدوداً لقضية الحدود/فلسطين/العلمانية يفرق بين الواقعة والتفسير الأخلاقي والسياسي، ويحترم الكرامة والحقوق الإنسانية.
5. يصمم تجربة أسبوعية مدنية وأخلاقية صغيرة لتحسين عادة تواصل أو حلقة تعلم، مع مقياس أثر وحدود واضحة.

## حدود تربوية غير قابلة للتفاوض

- لا تتحول الجلسات إلى مناظرة هوية قومية أو دينية أو سياسية، ولا يطلب من أحد إعلان موقفه أو تمثيل جماعة.
- لا يصوّر مجتمعاً أو شعباً أو ديناً ككتلة متجانسة، ولا يفسر الحاضر حصراً بماضٍ استعماري أو بمؤامرة كلية.
- عند فلسطين والحدود: تُصان كرامة المدنيين وحقوقهم؛ يدرس الخط الزمني والمصادر واللغة، ولا يقدم توجيه سياسي أو قانوني أو تعبوي.
- لا تتخذ مصطلحات «العلمانية» أو «الدولة الحديثة» أو «الهوية» شتائم أو مديحاً قبل تعريف المقصود والنطاق والمصدر.
- لا تدعو الأنشطة إلى خصومة أو مقاطعة أو تعبئة أو خرق قانون؛ الفعل مدني وتربوي وأخلاقي ومنخفض المخاطر.
- حلقات المصدر وتفريغات YouTube الآلية دلائل موضعية فقط؛ يراجع الميسر الفيديو الأصلي قبل الاقتباس أو العرض.
- مواد دورة أيمن تقدم إطار صاحبها حول الوعي واللغة والشبكات؛ تحلل كعدسة قابلة للنقد وليست تشخيصاً كلياً أو وصفة سياسية.
