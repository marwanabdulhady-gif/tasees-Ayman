## لا تصدر قبل تحقق كل بند
- [ ] المصدر الأصلي مراجع لكل اقتباس/رقم/دعوى حساسة؛ التفريغ ليس كافياً وحده.
- [ ] لا اختبار هوية أو تمثيل جماعة أو إلزام بموقف أو تجربة شخصية.
- [ ] أي وثيقة أصلية مسجلة: منشئ/تاريخ/رابط/ترجمة/سياق وحق استعمال.
- [ ] لا تطبيق للجاهلية أو ملصق هوياتي على جماعة أو دولة معاصرة.
- [ ] فلسطين/الحدود: كرامة وحقوق، لا تعبئة أو توجيه سياسي/قانوني أو لغة إقصاء.
- [ ] كل تجربة في الأسبوع 20 مدنية/تعليمية وقانونية واختيارية وقابلة للإيقاف.
- [ ] المسارات الثلاثة متاحة بلا ترتيب لقيمة المتعلمين.
