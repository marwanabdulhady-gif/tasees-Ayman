# الوحدة 5 v0.2 — الحداثة والاستعمار والهوية

**الأسابيع:** 17–20 من برنامج 24 أسبوعاً.  
**السؤال الجامع:** كيف ندرس الحداثة والاستعمار والحدود والهوية بوضوح تاريخي وكرامة إنسانية، من غير اختزال الناس في كتل أو تحويل التعلم إلى استقطاب؟  
**الحالة:** بناء مستقل v0.2؛ يحفظ v0.1 كما هي.

## دور «أين الطريق؟» المحدود
تدخل AT-01 وAT-10 وAT-12 وAT-13 وAT-09 كمواد أولية متتبعة: عدسات للتشخيص والتعلم والتمييز بين طبقات الادعاء وبناء قواعد مراجعة. لا تصبح تسمية لهويات حاضرة، أو سلطة تربوية أو روحية، أو وصفة سياسية/تنظيمية.

## حواجز ثابتة
لا اختبار هوية أو تمثيل جماعة؛ لا تطبيق «الجاهلية» أو أي ملصق على جماعات/دول معاصرة؛ لا مناظرة لكرامة المدنيين وحقوقهم؛ لا تعبئة أو توجيه سياسي/قانوني؛ لا ولاء أو مراقبة أو سلطة؛ والفعل مدني/تعليمي/قانوني ومنخفض المخاطر.
