# إعادة صياغة البرنامج v0.2 — دمج «أين الطريق؟»

## الغرض

هذا مجلد **إعادة بناء** منفصل؛ لا يستبدل الحزم المنشورة v0.1 أو يغيرها بصمت. يضيف سلسلة/كتاب `أين الطريق؟` إلى corpora البرنامج الأربعة:

1. `100 سؤال في التاريخ`.
2. `رحلة اليقين`.
3. `تأسيس وعي المسلم المعاصر` وموارد Telegram الموثقة.
4. `أين الطريق؟` — ملف PDF مرفق من المستخدم، صُدّر إلى 15 ملف Markdown قابل للتتبع.

## قاعدة الدمج

السلسلة الجديدة **خيطٌ بنائيٌّ ومادة أولية للتحليل** وليست «إجابة مقررة» ولا مرجعاً خارجياً مستقلاً لكل دعوى وردت فيها. كل استخدام في نسخة v0.2 يحمل: الحلقة/الصفحة، نوع الدعوى، الدور التربوي، والمصدر الخارجي اللازم للتحقق عند وجود ادعاء تاريخي أو علمي أو فقهي أو قانوني.

## ما سيتغير

- يعاد صياغة الأسابيع 1–24 بحيث يصبح مسار «الاستعداد → تشخيص المشكلة → التفكير والتلقي → المعنى والممارسة → الجماعة والتحول → الفعل المسؤول» مرئياً عبر الوحدات الست.
- تحفظ الأسئلة التاريخية والعلمية والحديثة في مواضعها؛ لا يُختزل البرنامج في مصدر واحد أو في خط وعظي أحادي.
- تعاد بناء الملفات المصدرية وسجلات الموارد وأدلة الميسر ودفاتر المتعلم والعروض وPilot لكل وحدة تحت النسخة `v0.2`.
